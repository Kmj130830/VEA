# S5API decoded model JSON object-tree port

Date: 2026-11-20

## Scope

This change ports one bounded stage of the S5API model-loading path: parsing an already-decoded UTF-8 JSON document into the typed value tree used by subsequent parameter lookups. It does not parse the outer .vtb2 container, transform its opaque payload, load the complete Megpoid model, or synthesize audio.

## Static basis

The supplied authorized S5API.dll was analyzed statically, not executed. The recovered call path shows a JSON dispatcher producing object, array, string, numeric, boolean and null values. Consumers use a type tag at object offset +0x40 and a payload/value at +0x48. Recurrent parameters are located using the salted MD5 lookup helper already ported in NativeS5TensorBridge.

The recurrent property family includes weight_ih_l{layer}, weight_hh_l{layer}, bias_ih_l{layer} and bias_hh_l{layer}, with _reverse variants. Typed strings use *F32, *F16 and *S32 markers.

## Android implementation

S5ModelObjectTree.kt provides strict UTF-8 decoding, full JSON grammar, paired surrogate handling, duplicate-key rejection and configurable input (128 MiB default), nesting-depth (128) and value-node (2 million) limits. It supports root-object validation, key lookup, salted-name lookup, numeric-array conversion and delegation of typed tensor strings to the existing native decoders.

Tests inject a deterministic key hasher and tensor decoder so the parser can be tested without loading Android JNI libraries.

## Deliberate limits

- The parser starts after any outer container and pre-JSON byte transformation.
- No assumptions are made about the opaque 124-byte container metadata or complete .vtb2 payload grammar.
- The separate PR #4 F16 callback path is not automatically selected by this parser; integration remains pending branch reconciliation.
- Recurrent parameter storage has three gate blocks, but gate ordering and forward equations remain unverified. This is not a GRU implementation.
- No Megpoid V7 PCM output is generated by this parser.

Passing parser tests and APK assembly verify the JSON/value-tree layer only, not complete model loading or singing synthesis.
